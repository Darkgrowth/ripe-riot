# Sunpatch audio sources

`render_score.py` is the editable original composition and deterministic instrument renderer. It needs Python, NumPy, and FFmpeg on PATH. Run `python tools/audio/render_score.py` to write the four OGG files and score metadata into `public/audio`; use `--output <directory>` to prepare a candidate without modifying served assets. No recordings or third-party samples are used.

The 48-bar score is 4/4 at 96 BPM, exactly 120 seconds. The calm foundation contains a jaunty plucked melody, fingerpicked harmony, warm alternating bass, and quiet breathy woodwind answers at four-bar cadences. Busy adds banjo picking and wooden ticks; trouble adds low pizzicato and wooden percussion. All notes and tails share the same loop grid. The demo arranges these layers for listening.

Run `python tools/audio/verify_audio.py` (or `--directory <candidate-directory>`) to decode the compressed deliverables and measure duration, peaks, and endpoint discontinuity. `node tools/audio/check_audio.mjs` verifies graph routing, mute, settings persistence, bounded transient nodes, bar-aligned transitions, warning duck/recovery, restored legendary phases, and lifecycle cleanup using a CPU mock. These checks do not establish subjective musical quality or actual browser visibility behavior.

The browser fixtures must only be run when authorized on an isolated server and when no other browser test owns the slot. The older `browser_audio_check.mjs` headed setting is unsuitable during live play. `record_game_audio.mjs` explicitly restricts capture to staging ports 5192/5193, headless software rendering at 320x180, and disconnected speaker output while recording. Do not run either against the original project. The earlier data-URL export bug was corrected. A complete ten-minute ordinary-input recording is delivered at `capture/staging-qa/normal-input-service-route/session.mp4`, with `gameplay-audio.mp3` containing the actual post-master mix. Its raw WebM remains available; Opus parser warnings prompted the standard MP4/MP3 export, both of which decode fully without errors. The composed demo is also valid and listenable. Human headphone/speaker evaluation remains outstanding.

Runtime controls default to master .7, music .35, effects .9, and ambience .5. All routes meet at the master gain. Warning/result/payoff phrases briefly halve music, then restore the current saved music volume. Event presentation drives the musical layers; the actual legendary phase also covers restored games. Muting never grants a cue an exception.
